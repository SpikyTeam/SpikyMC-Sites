1.1.0 October 11, 2026 Stable

Added:

  • Ely.by accounts: sign in with an Ely.by account, with custom skins and support for servers that only allow Ely.by
  • Ely.by game patch: automatic download and application of the Ely.by patch (always / for Ely.by or offline accounts / for Ely.by accounts only / never)

Changed:

  • Offline accounts accept any nickname, with no length/charset validation and no "allow invalid usernames" toggle

Fixed:

  • Localization
  • Issues from previous versions

Known Issues:

  • Sign-in with Ely.by via the button is broken in the non-portable builds, but signing in with a code still works. Workaround: use https://account.ely.by/code. The portable builds are unaffected. Fixed in 1.1.1.
