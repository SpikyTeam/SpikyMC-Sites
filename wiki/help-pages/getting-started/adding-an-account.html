Добавление аккаунта

В SpikyMC можно добавить несколько аккаунтов и переключаться между ними без повторного входа.

Поддерживаемые типы аккаунтов

  • Microsoft — официальный аккаунт Minecraft (покупка через minecraft.net)
  • Ely.by — бесплатный аккаунт для игры на серверах Ely.by
  • Оффлайн (имя игрока) — игра без аккаунта, только на серверах без проверки лицензии

Как добавить аккаунт

  1. Откройте лаунчер и перейдите в раздел аккаунтов.
  2. Нажмите «Добавить аккаунт».
  3. Выберите тип аккаунта и следуйте инструкциям на экране.
  4. Для Microsoft пройдите авторизацию в браузере через код.
  5. Для Ely.by введите логин и пароль от сервиса.

После добавления аккаунт появится в списке. Выберите его перед запуском инстанса, чтобы играть от этого имени.

Если что-то не работает — проверьте подключение к интернету и настройки прокси (Настройки прокси).
